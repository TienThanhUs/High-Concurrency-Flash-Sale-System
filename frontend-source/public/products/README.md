# THƯ MỤC ẢNH SẢN PHẨM PIXEL (PUBLIC/PRODUCTS)

Thư mục này chứa các ảnh pixel art dành cho các loại sản phẩm trong FlashMart.

### 1. Quy chuẩn ảnh:
- **Định dạng:** PNG (`.png`), nền trong suốt (transparent).
- **Kích thước chuẩn:** `32x32` px hoặc `64x64` px.
- **Phong cách:** Pixel art 8-bit / 16-bit, viền sắc nét, không đổ bóng mờ hay gradient.

### 2. Tên file theo từ khóa (loại sản phẩm):
Component `ProductImage` sẽ tự động đoán loại sản phẩm từ tên và tìm ảnh tương ứng:
- `ban-phim.png` → Bàn phím cơ, phím retro...
- `chuot.png` → Chuột gaming, chuột không dây...
- `tai-nghe.png` → Tai nghe bluetooth, headphone...
- `tay-cam.png` → Tay cầm chơi game, gamepad, controller...
- `the-nho.png` → Thẻ nhớ SD, thẻ MicroSD...
- `sac.png` → Đế sạc nhanh, củ sạc, cáp sạc...
- `dong-ho.png` → Đồng hồ thông minh, smart watch...
- `loa.png` → Loa bluetooth 8-bit...
- `man-hinh.png` → Màn hình gaming...

> **Lưu ý:** Nếu chưa có file PNG hoặc ảnh tải lỗi, hệ thống sẽ tự động vẽ sprite pixel art độc nhất theo hash của mã `productId`.
